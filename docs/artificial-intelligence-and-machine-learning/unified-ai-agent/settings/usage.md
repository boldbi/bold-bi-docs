# Usage

The Usage page provides insights into AI Assistant consumption, helping users monitor requests, token usage, model adoption, skill utilization, and overall AI activity within the AI Assistant.

## Accessing Usage
To view AI Assistant usage metrics

1. Navigate to AI Assistant → Settings → Usage.

2. Use the time-period selector to filter usage information for a specific duration.

The Usage page displays key metrics and analytics related to AI Assistant activity.

## Usage Metrics

The page displays key metrics:

- **Active Users** - Number of users using AI Assistant this period
- **Tokens Used** - Total LLM tokens consumed (input + output)
- **Requests** - Total number of AI Assistant requests processed

## Viewing Usage Details

**Tokens per Day** - Chart showing daily token consumption broken down by:
- Input Tokens (sent to LLM)
- Output Tokens (generated by LLM)

**Where Tokens Go** - The Where Tokens Go widget shows how token consumption is distributed across AI Assistant features, skills, and MCP tool executions. This helps identify which capabilities contribute most to AI usage.

**Feature and Model Breakdown** - Table showing:
- **Date** - When requests were made
- **Feature** - Which AI Assistant feature was used
- **Model** - Which LLM model processed the request (OpenAI, Azure OpenAI, Claude, etc.)
- **Requests** - Number of requests for that combination

**Most Active Users** - List of users with highest token consumption.
