# Proportion Widgets in Modern Dashboards

Proportion widgets show how each part contributes to a whole. Use these widgets when you want to explain percentage contribution, segment share, or part-to-total composition.

These widgets are useful for scenarios such as sales share by product line, expense contribution by department, or lead conversion stages in a funnel.

## Available widgets

| Widget | Description |
|---|---|
| [Pie Chart](/visualizing-data/visualization-v2-widgets/proportion/pie-chart/) | Displays part-to-whole contribution using circular segments. |
| [Doughnut Chart](/visualizing-data/visualization-v2-widgets/proportion/doughnut-chart/) | Displays part-to-whole contribution with a hollow center for a cleaner circular layout. |
| [Funnel Chart](/visualizing-data/visualization-v2-widgets/proportion/funnel-chart/) | Shows stage-based reduction through a business process. |
| [Pyramid Chart](/visualizing-data/visualization-v2-widgets/proportion/pyramid-chart/) | Shows proportional distribution in a layered pyramid layout. |
