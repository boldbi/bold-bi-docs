# Deviation Widgets in Modern Dashboards

Deviation widgets help users understand status, progress, or variance against an expected value. Use these widgets when the primary question is how far a value has moved toward, above, or below a target.

## Available widgets

| Widget | Description |
|---|---|
| [Radial Gauge](/visualizing-data/visualization-v2-widgets/deviation/radial-gauge/) | Displays progress or status in a circular gauge format. |
