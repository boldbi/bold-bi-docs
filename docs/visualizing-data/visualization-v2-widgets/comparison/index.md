# Comparison

Comparison widgets help you compare values across categories, series, or grouped business data. Use these widgets when you want to show differences between items, track ranking, or compare multiple measures side by side.

These widgets are best suited for scenarios such as comparing sales by region, revenue by product, or performance across departments over the same reporting period.

## Available widgets

| Widget | Description |
|---|---|
| [Bar Chart](/visualizing-data/visualization-v2-widgets/comparison/bar-chart/) | Displays horizontal bars and is useful when category labels are long. |
| [Column Chart](/visualizing-data/visualization-v2-widgets/comparison/column-chart/) | Displays vertical columns and works well for straightforward category comparison. |
| [Stacked Bar Chart](/visualizing-data/visualization-v2-widgets/comparison/stacked-bar-chart/) | Shows how subcategories contribute to a total in a horizontal layout. |
| [Stacked Column Chart](/visualizing-data/visualization-v2-widgets/comparison/stacked-column-chart/) | Shows part-to-total contribution using vertical columns. |
| [100% Stacked Bar Chart](/visualizing-data/visualization-v2-widgets/comparison/100-stacked-bar-chart/) | Compares percentage contribution across categories in a horizontal view. |
| [100% Stacked Column Chart](/visualizing-data/visualization-v2-widgets/comparison/100-stacked-column-chart/) | Compares percentage contribution across categories in a vertical view. |
| [Radar Polar Chart](/visualizing-data/visualization-v2-widgets/comparison/radar-polar-chart/) | Compares multiple dimensions across categories using a circular or radial layout. |
