# Line Widget

The Line widget adds a horizontal or vertical separator to a dashboard. Use it to distinguish dashboard sections and reinforce the layout structure.

## Adding a Line Widget

1. Add the **Line** widget to the design canvas.
2. Resize and position it between the dashboard sections you want to separate.
3. Open the properties panel to configure its appearance.

## Formatting the Line Widget

### General Settings

Refer to [General Settings](/visualizing-data/visualization-v2-widgets/properties/widget-container-customization/#general-settings) for information about configuring the widget type, unique name, title, subtitle, and description shown for the widget.

### Basic Settings

#### Vertical Orientation

Switches the line between vertical and horizontal.

#### Thickness

Sets the line width from `1` through `50` pixels.

#### Padding

Sets the space between the line and its widget boundary from `1` through `50` pixels.

#### Line Type

Selects **Solid**, **Dotted**, or **Dashed**.

#### Color

Sets the line color.

### Container Appearance

Refer to [Container Appearance](/visualizing-data/visualization-v2-widgets/properties/widget-container-customization/#container-appearance) for the supported container settings.

> **NOTE:** Header, maximize, and pin actions are not available for the Line widget.
