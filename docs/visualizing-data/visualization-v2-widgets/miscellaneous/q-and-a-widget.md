# Q&A Widget

The Q&A widget lets viewers ask natural-language questions and receive answers based on the configured dashboard data.

## Before You Begin

An administrator must configure the Q&A service and its required AI provider settings. The widget displays configuration guidance when the service or credentials are unavailable.

## Adding a Q&A Widget

1. Add the **Q&A Widget** to the design canvas.
2. Resize it to provide enough space for questions and responses.
3. Preview the dashboard and enter a question about the configured data.

## Using the Q&A Widget

Viewers enter a question in the prompt area. The widget sends it through the configured Q&A service and displays the returned response. Available help and feedback actions depend on site configuration.

## Formatting the Q&A Widget

The Q&A widget does not expose a widget-specific property category. Its available title and container options use the global container settings described below.
