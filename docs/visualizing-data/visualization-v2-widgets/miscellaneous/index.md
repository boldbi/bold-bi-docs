# Miscellaneous

Miscellaneous widgets support layout, descriptive content, actions, and custom viewer experiences. Use these widgets when the dashboard needs more than analytical charts, such as explanatory text, images, buttons, tabs, or specialized content areas.

## Available widgets

| Widget | Description |
|---|---|
| [Image](/visualizing-data/visualization-v2-widgets/miscellaneous/image/) | Displays static or dynamic images. |
| [Tab](/visualizing-data/visualization-v2-widgets/miscellaneous/tab-widget/) | Groups multiple widgets under tabbed navigation. |
| [Combined Widget](/visualizing-data/visualization-v2-widgets/miscellaneous/combine-widget/) | Displays multiple widgets together in a single combined layout. |
| [Rich Text Editor](/visualizing-data/visualization-v2-widgets/miscellaneous/text/) | Displays formatted text content. |
| [Line](/visualizing-data/visualization-v2-widgets/miscellaneous/line-widget/) | Displays a visual separator or layout line. |
| [Q&A](/visualizing-data/visualization-v2-widgets/miscellaneous/q-and-a-widget/) | Provides a question-driven interaction experience. |
| [Button](/visualizing-data/visualization-v2-widgets/miscellaneous/button-widget/) | Adds a clickable action or navigation element. |
