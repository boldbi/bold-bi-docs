# Combined Widget

The Combined Widget groups multiple dashboard widgets into one container that can be moved and resized. Use it to preserve a related layout or build a layered composition.

![Combined Widget](/static/assets/visualizing-data/visualization-widgets/images/combine-widgets/combine_widgets.png)

## Configuring the Combined Widget

1. Add the **Combined Widget** to the design canvas.
2. Drag the required widgets into its container.
3. Move or resize the container to update the grouped widgets together.

## Formatting the Combined Widget

### General Settings

Refer to [General Settings](/visualizing-data/visualization-v2-widgets/properties/widget-container-customization/#general-settings) for information about configuring the widget type, unique name, title, subtitle, and description shown for the widget.

### Basic Settings

#### Widgets Order

Lists the child widgets and controls their front-to-back order.

#### Apply Stack Order

Applies the configured order when child widgets overlap.

#### Show Child Widget Menu Icons

Displays supported menu icons on widgets placed inside the Combined Widget. It is disabled when the parent widget menu is hidden.

### Container Appearance

Refer to [Container Appearance](/visualizing-data/visualization-v2-widgets/properties/widget-container-customization/#container-appearance) for background, border, radius, transparency, padding, and shadow settings.

### Container Actions

Refer to [Container Actions](/visualizing-data/visualization-v2-widgets/properties/widget-container-customization/#container-actions) for maximize, commenting, and pinning options.

### Export Settings

Refer to [Export Options](/visualizing-data/visualization-v2-widgets/properties/export-options/) for exporting the visible grouped widgets as one output.
