# Distribution

Distribution widgets help users understand trends, movement, spread, and patterns across categories or time. Use these widgets when you need to show how values change, how they are distributed, or how points relate over a continuous axis.

These widgets are commonly used for time-series analysis, trend tracking, volume changes, and correlation-style views.

## Available widgets

| Widget | Description |
|---|---|
| [Area Chart](/visualizing-data/visualization-v2-widgets/distribution/area-chart/) | Emphasizes the magnitude of values over a continuous axis. |
| [Stacked Area Chart](/visualizing-data/visualization-v2-widgets/distribution/stacked-area-chart/) | Shows how multiple series contribute to a total over a continuous axis. |
| [100% Stacked Area Chart](/visualizing-data/visualization-v2-widgets/distribution/100-stacked-area-chart/) | Shows percentage contribution over a continuous axis. |
| [Line Chart](/visualizing-data/visualization-v2-widgets/distribution/line-chart/) | Displays trends clearly over time or ordered categories. |
| [Spline Chart](/visualizing-data/visualization-v2-widgets/distribution/spline-chart/) | Displays a smoothed trend line. |
| [Spline Area Chart](/visualizing-data/visualization-v2-widgets/distribution/spline-area-chart/) | Combines smoothed trend display with area emphasis. |
| [Scatter Chart](/visualizing-data/visualization-v2-widgets/distribution/scatter-chart/) | Shows the distribution and relationship of points across X and Y axes. |
