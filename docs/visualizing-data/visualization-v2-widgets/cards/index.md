# Cards

Card widgets highlight important business numbers in a compact and easy-to-scan format. Use these widgets when you want viewers to notice a key value immediately without interpreting axes or multiple series.

These widgets are commonly used for KPIs such as revenue, profit, margin, target achievement, variance, and trend highlights on executive dashboards.

## Available widgets

| Widget | Description |
|---|---|
| [Number Card](/visualizing-data/visualization-v2-widgets/cards/number-card/) | Displays a single important measure with optional supporting content. |
| [KPI Card](/visualizing-data/visualization-v2-widgets/cards/kpi-card/) | Displays a main KPI along with supporting values, status indication, and trend-focused elements. |
