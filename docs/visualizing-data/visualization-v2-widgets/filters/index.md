# Filters

Filter widgets let viewers interactively narrow dashboard data. Use these widgets when users need to select values, enter text, or choose dates to control what the dashboard displays.

These widgets are typically placed at the top or side of a dashboard to support guided data exploration.

## Available widgets

| Widget | Description |
|---|---|
| [Combo Box](/visualizing-data/visualization-v2-widgets/filters/combo-box/) | Lets viewers select one or more values from a drop-down list. |
| [List Box](/visualizing-data/visualization-v2-widgets/filters/list-box/) | Lets viewers select values from a visible list. |
| [Date Picker](/visualizing-data/visualization-v2-widgets/filters/date-picker/) | Lets viewers filter data using date or date-range selection. |
| [Text Filter](/visualizing-data/visualization-v2-widgets/filters/text-filter/) | Lets viewers type or search for matching text values. |
| [Range Navigator](/visualizing-data/visualization-v2-widgets/filters/range-navigator/) | Lets viewers filter data by choosing a value range visually. |
| [Period Over Period](/visualizing-data/visualization-v2-widgets/filters/period-over-period/) | Lets viewers compare one date period with another through filter-based period selection. |
