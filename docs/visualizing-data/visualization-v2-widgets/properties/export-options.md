# Export Options in Modern Widgets

Export options in Bold BI control which download and data-access commands viewers can use from a widget's menu. Available formats depend on the widget type and the permissions assigned to the viewer. Any dashboard can be exported to PowerPoint, Image, PDF, Excel or CSV. The options on this page control which of these commands a viewer sees on a widget menu.

## Properties

### Allow CSV Export

Lets viewers export the widget data as a comma-separated values file.

#### Allow Excel Export

Lets viewers export supported widget data as an Excel workbook.

#### Allow Image Export

Lets viewers download the rendered widget as an image.

#### Allow PDF Export

Lets viewers download the rendered widget as a PDF document.

#### Allow View Underlying Data

Lets viewers inspect the records used to produce the visual. Access remains subject to the user's data permissions.

> **NOTE:** A property is shown only when the selected widget supports that export format or action.
