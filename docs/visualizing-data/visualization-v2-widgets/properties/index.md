# Widget Properties

This section documents properties shared across multiple Bold BI Modern widgets. Instead of repeating these settings on every widget page, each widget page links to the relevant property page here.

Each property page clearly lists the widgets that do **not** support that property. If a widget is not listed in the unsupported table, the property applies to it.

## Available Properties

| Property | Description |
|---|---|
| [Data Configuration](/visualizing-data/visualization-v2-widgets/properties/data-configuration/) | Assign fields and configure aggregation, sorting, filtering, formatting, and drill-down. |
| [Tooltip Settings](/visualizing-data/visualization-v2-widgets/properties/tooltip-settings/) | Control the visibility, content, and appearance of data point tooltips. |
| [Legend Settings](/visualizing-data/visualization-v2-widgets/properties/legend-settings/) | Configure legend visibility, position, alignment, shape, and overflow behaviour. |
| [Axis Settings](/visualizing-data/visualization-v2-widgets/properties/axis-settings/) | Customize category and value axis titles, labels, rotation, and overflow handling. |
| [Axis Range Settings](/visualizing-data/visualization-v2-widgets/properties/axis-range-settings/) | Set manual minimum, maximum, and interval values for the value axis using static values or dashboard parameters. |
| [Gridlines](/visualizing-data/visualization-v2-widgets/properties/gridlines/) | Show or hide primary and secondary gridlines on the chart plot area. |
| [Forecast Settings](/visualizing-data/visualization-v2-widgets/properties/forecast-settings/) | Extend an eligible Line or Spline series with predicted values and a confidence band. |
| [Trendline Settings](/visualizing-data/visualization-v2-widgets/properties/trendline-settings/) | Add, edit, or remove a trendline from an eligible non-stacked Cartesian chart. |
| [Conditional Formatting](/visualizing-data/visualization-v2-widgets/properties/conditional-formatting/) | Apply rule-based or individual color and style rules driven by data values. |
| [Value Formatting](/visualizing-data/visualization-v2-widgets/properties/value-formatting/) | Format measure values using number, currency, percentage, or date patterns. |
| [Font Settings](/visualizing-data/visualization-v2-widgets/properties/font-settings/) | Adjust the font family, size, weight, and color for widget text elements. |
| [Filter Settings](/visualizing-data/visualization-v2-widgets/properties/filter-settings/) | Apply widget-level filters and control cross-filter interaction with other widgets. |
| [Linking](/visualizing-data/visualization-v2-widgets/properties/linking/) | Configure URL or dashboard navigation triggered by a click on a data point. |
| [Inter-Widget Linking](/visualizing-data/visualization-v2-widgets/properties/inter-widget-linking/) | Link supported source widgets to a Tab widget so selections can switch tabs and pass the related filter context. |
| [Widget Container Customization](/visualizing-data/visualization-v2-widgets/properties/widget-container-customization/) | Set the widget title, subtitle, description, background, border, shadow, and other container-level display options. |
| [Export Options](/visualizing-data/visualization-v2-widgets/properties/export-options/) | Control the download formats and underlying-data actions available from a widget. |
| [Responsive Behavior](/visualizing-data/visualization-v2-widgets/properties/responsive-behavior/) | Configure and validate how widget content adapts to different sizes. |
