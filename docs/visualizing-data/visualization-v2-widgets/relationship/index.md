# Relationship

Relationship widgets help you analyze how data points connect through geography, hierarchy, tabular structure, density, or distribution across an area. Use these widgets when you need to understand patterns between values rather than only compare totals.

These widgets are commonly used for location analysis, tabular reporting, heat-based pattern detection, and hierarchical breakdowns.

## Available widgets

| Widget | Description |
|---|---|
| [Map](/visualizing-data/visualization-v2-widgets/relationship/map/) | Displays data across geographic regions or locations. |
| [Azure Maps](/visualizing-data/visualization-v2-widgets/relationship/azure-maps/) | Displays geographic data using Azure Maps layers and markers. |
| [Grid](/visualizing-data/visualization-v2-widgets/relationship/grid/) | Presents detailed records in a table layout. |
| [Pivot Grid](/visualizing-data/visualization-v2-widgets/relationship/pivot-grid/) | Summarizes data in a multidimensional matrix for slice-and-dice analysis. |
| [Heatmap](/visualizing-data/visualization-v2-widgets/relationship/heat-map/) | Highlights density and intensity using color variation. |
| [Treemap](/visualizing-data/visualization-v2-widgets/relationship/tree-map/) | Displays hierarchical part-to-whole data as nested rectangles. |
