# Bold BI MCP Integration 
The Bold BI MCP Integration enables AI assistants and MCP-compatible applications to interact with Bold BI through the Model Context Protocol (MCP). By connecting an MCP client, you can access and work with dashboards, data sources, analytics content, and documentation using structured tools and natural language interactions.

This section provides an overview of the available MCP integrations and helps you get started with the appropriate implementation based on your use case.
