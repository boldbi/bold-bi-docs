# Go to Dependent Dashboard Page

This section explains how to navigate to the dependent dashboard for a specific widget from the pinboard in the Bold BI application.

### Steps to Navigate Dependent Dashboard from the Pinboard

Hover the mouse over the specific widget. It shows the `Go to Dashboard` icon in the top right of the section. Clicking this icon opens the respective dashboard in a new tab.
