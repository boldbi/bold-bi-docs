# Upgrade Center

## Overview

Upgrade Center is an in-application upgrade experience for Bold BI deployments. It helps administrators check for available product updates, review the target version, validate the environment, back up affected database tables, apply Kubernetes deployment image updates, monitor upgrade progress, and roll back when recovery is required.

The Upgrade Center is designed to reduce manual upgrade steps and provide a single place to track the full upgrade operation. Administrators can review stage-wise progress, validation results, complete operation logs, Playwright HTML reports, cleanup status, and upgrade history from the Upgrade Center UI.

Upgrade Center is currently supported for Kubernetes deployments. Use the documentation below to enable and use Upgrade Center in Kubernetes environments.
